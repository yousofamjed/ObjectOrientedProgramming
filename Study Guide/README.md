## 📖 How to Use These Guides

For each topic listed above, we advise you to study in the following order to maximize your understanding:

1. **Review the Core Files:** Start with the summary files and slides prepared by the course instructors (e.g., *Ms. Ayat Droos* or *Dana Altaher's* notes).
2. **Watch the Lectures:** If a concept is still unclear, watch the corresponding YouTube video explanations prepared by *Dr. Ibrahim Albluwi*.
3. **Analyze Code Examples:** Review the practical implementations and revision codes provided by *Dr. Samer Alsawalha*.
4. **Test Your Knowledge:** Practice with past quizzes relevant to the specific topic.
5. **Apply in Labs:** Complete the previous lab assignments linked in each guide to ensure you can write the code from scratch.
